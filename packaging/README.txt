Style Atlas {version}

[简体中文]
1. Windows：双击“Style Atlas.bat”。Linux：在终端里运行 ./style-atlas.sh
2. 第一次会自动下载并安装需要的组件（有 NVIDIA 显卡约 2.5 GB，没有约 200 MB），
   窗口里会显示进度。装好后会创建“Style Atlas”快捷方式（Windows 在桌面，
   Linux 在应用程序菜单），并打开程序。
3. 之后直接用快捷方式打开。
第一次打开图片文件夹时，还会下载一次画风模型（约 2.4 GB）。
更新：有新版本时程序会提示，按“更新”再重启即可；图片、结果和设置都不会改动。
把这个文件夹放在普通位置（例如 D:\StyleAtlas），不要放进 C:\Program Files。
搬动这个文件夹后，再双击一次“Style Atlas.bat”，快捷方式就会指向新位置。
完整说明：https://github.com/Rinne414/style-atlas

[English]
1. Windows: double-click "Style Atlas.bat". Linux: run ./style-atlas.sh in a terminal.
2. The first time it downloads and installs what it needs (about 2.5 GB with an NVIDIA card,
   200 MB without) and shows the progress. Then it makes a "Style Atlas" shortcut (on the
   desktop on Windows, in the application menu on Linux) and opens the program.
3. After that, open it with the shortcut.
The first folder you open also downloads the style model once (about 2.4 GB).
Updates: the program tells you about a new version; press "Update", then restart. Your
pictures, results and settings are not touched.
Keep this folder somewhere ordinary (for example D:\StyleAtlas), not in C:\Program Files.
After moving this folder, double-click "Style Atlas.bat" once more to point the shortcut at it.
Full guide: https://github.com/Rinne414/style-atlas
