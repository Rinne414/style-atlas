# Style Atlas

把一个图片文件夹按画风分组、找画风相近的图、整理 LoRA 训练集。全部在你自己的电脑上运行。

简体中文 · [English](README.md)

![图片按画风分组，右侧列出每组的外观描述](docs/images/map.jpg)

（截图里的图片是 `style-atlas demo` 生成的抽象画风，不是任何人的作品。）

## 下载和启动

### Windows 10 / 11

1. 到[最新版本页面](https://github.com/Rinne414/style-atlas/releases/latest)下载
   **`StyleAtlas-<版本>-windows.zip`**。
2. 解压到普通的位置，例如 `D:\StyleAtlas`。不要放进 `C:\Program Files`，也不要放在很深的文件夹里：
   Windows 对路径长度有限制，路径太长时启动程序会提示并停下。
3. 打开解压出来的 `StyleAtlas` 文件夹，双击 **`Style Atlas.bat`**。
   - 第一次会弹出一个命令窗口，把需要的组件装进这个文件夹：torch（有 NVIDIA 显卡约 2.5 GB，
     没有约 200 MB）和约 100 MB 的其他组件。不需要另外安装 Python；除了快捷方式，不会改动这个
     文件夹以外的东西。下载中断的话，再双击一次就会接着装。
   - 装好后会在桌面创建 **Style Atlas** 快捷方式并打开程序，命令窗口会自己关闭。
4. 之后直接双击桌面快捷方式打开。

第一次双击 .bat 时，Windows 可能显示“Windows 已保护你的电脑”（文件没有代码签名）：
按 **更多信息 → 仍要运行**。

### Linux（x86-64）

1. 到[最新版本页面](https://github.com/Rinne414/style-atlas/releases/latest)下载
   **`StyleAtlas-<版本>-linux.tar.gz`**。
2. 在终端里运行：

   ```sh
   tar xzf StyleAtlas-<版本>-linux.tar.gz
   cd StyleAtlas
   ./style-atlas.sh
   ```

3. 第一次运行会把需要的组件装进这个文件夹（和 Windows 一样，另外约 300 MB 是窗口用的 Qt WebEngine），
   在应用程序菜单里加上 **Style Atlas**，然后打开程序。

窗口由 Qt 绘制。大多数桌面 Linux 已经有它需要的系统库。缺少时，`./style-atlas.sh` 会列出缺少的库并给出安装命令。在最小安装的 Ubuntu 24.04 上是 `sudo apt install libxkbfile1`，X11 会话还需要 `libxcb-cursor0 libxcb-icccm4 libxcb-image0 libxcb-keysyms1 libxcb-render-util0 libxcb-shape0 libxcb-util1 libxcb-xkb1 libxkbcommon-x11-0`。

## 怎么用

1. 按 **打开图片文件夹…**，或把文件夹直接拖进窗口。开过的文件夹会列在开始页面。
2. 第一次打开文件夹时会下载一次画风模型（2.4 GB，之后保留 1.2 GB 的精简版），然后计算每张图的画风：
   用 8 个 CPU 线程约每秒 2.5～4 张（实测）；有 NVIDIA 显卡通常快很多。结果会缓存，再次打开同一个
   文件夹很快。
3. 地图上的图按画风分组。点右边的一组看它的全部图；双击图片看大图；按 → 可以一张一张看完全部的图。
4. 要训练 LoRA：打开 **LoRA 数据集** 标签页，按“检查 → 整理画风组 → 导出”做。导出会写出 kohya
   文件夹，以及 kohya sd-scripts、diffusion-pipe、OneTrainer、ai-toolkit 的数据集配置。
5. 左上角的 **← 开始页面** 关掉这个文件夹；**新窗口** 在旁边再开一个文件夹。程序开着时再启动一次，
   也会开一个新窗口。

图解操作：[docs/WEB_GUIDE.md](docs/WEB_GUIDE.md)。完整的 LoRA 流程：[docs/LORA_GUIDE.md](docs/LORA_GUIDE.md)。

## 更新

程序每次启动时会向 GitHub 查询有没有新版本；不想查询的话，在开始页面取消勾选 **启动时检查更新**。
有新版本时，开始页面和地图上会提示。按 **更新** 之前什么都不会改变：按下后会下载新的程序代码（几 MB），
用发布页面上的 SHA256 校验值核对（对不上就丢弃），再按 **立即重启** 换上新版。你的图片、结果、分组、
名称和设置都不会改动。如果新版本需要更新内置的 Python，程序会提示你重新下载完整安装包。

## 会连网的地方

| 什么时候 | 做什么 | 连到哪里 |
|---|---|---|
| 第一次启动 | 下载 Python 组件（torch、numpy 等），装进程序文件夹 | pypi.org、download.pytorch.org |
| 第一次打开文件夹 | 下载 CSD 画风模型（2.4 GB） | huggingface.co |
| 每次启动（可关闭） | 查询最新版本号和更新内容 | api.github.com |
| 按“更新”时 | 下载新的程序代码 | github.com |

除此之外没有任何联网：图片、结果、评分和名称都只留在你的电脑上，没有账号，也不收集使用数据。
程序的本地服务器只接受这台电脑（127.0.0.1）的连接。用 **保存为分享用地图** 存出的文件里含有你选的图片，
收到文件的人都看得到。

## 系统要求

- Windows 10 / 11（64 位）或 Linux x86-64。不支持 macOS。
- 有 NVIDIA 显卡时约需 10 GB 可用空间（没有显卡约 5 GB）。
- NVIDIA 显卡不是必需的；torch 的 CUDA 12.8 版需要较新的显卡驱动。没有显卡时全部用 CPU 运行，会慢一些。

## 遇到问题

- **第一次安装到一半停了**（网络问题）：再双击一次 `Style Atlas.bat`，会接着装。
- **下载很慢或连不上**（例如在中国大陆）：画风模型可设置环境变量 `HF_ENDPOINT=https://hf-mirror.com`，
  组件可设置 `PIP_INDEX_URL`（例如 `https://pypi.tuna.tsinghua.edu.cn/simple`），再重新启动。
  torch 本身始终从 download.pytorch.org 下载。
- **搬动了文件夹**：再双击一次 `Style Atlas.bat`，快捷方式就会指向新位置。
- **画面上出现错误**：程序的信息记录在程序文件夹里的 `style-atlas.log`，回报问题时请附上这个文件。
- **想指定 CPU 版或显卡版的 torch**：设置环境变量 `STYLE_ATLAS_TORCH=cpu`（或 `cuda`），再双击
  `Style Atlas.bat`。

## 能做什么

style-atlas 会看每张图“怎么画”（不是画了什么），自动把画风相近的图分在一起。它用 CSD 这个画风辨识模型，把每张图转成一组“画风特征”，再拿这些特征做下面几件事：

| 你想做的事 | 怎么做 |
|---|---|
| **训练 LoRA 前整理数据集**：分出不同画风，或把同一位画师分成几个时期（文件名有时间时用 `--granularity timeline --time name`：按时间切成连续的时期，并告诉你画风是有转折、只是渐变，还是没找到和时间的关系（作品少时只是提示）；时期是初步整理，请在网页上确认），排除重复图与离群图，导出成 kohya 文件夹 | `cluster --layout kohya --dedupe`（分时期加 `--granularity period`），或网页界面的“导出文件夹” |
| **找画风相近的图**：一张或同画风的几张图当范例，也能把结果直接复制成文件夹（实测：同一位画师的其他作品，第一名猜中约 47%，前 10 名内约 71%） | 网页界面拖图进去，或用 `search`（`--combine`、`--copy-to`） |
| **整理很多位画师的图库**：按画师分组（20 位以上的图库比默认的自动分组更贴近画师） | `cluster --granularity artists`，或网页分组菜单的“按画师” |
| **这张图像哪位画师？**：图库按画师（或画风）分文件夹时，列出最像的文件夹，并说第一名有多可信（依第一名领先多少，实测正确率 35%~99%；同一位画师早期或后期的作品可能更像别人） | `search --by-folder` |
| **3D 画风地图**：缩略图浮在 3D 空间，可转动，点一下就看最接近的画风；也可以每位画师一个点，看谁和谁画风相近 | `map`（画师地图加 `--by-folder`；网页界面的“画师地图”按钮也可以），或网页界面的“保存为分享用地图”（单个 HTML 文件，可直接传给朋友）；“查看”菜单的“保存为图片”或 P 键保存为图片 |
| **检查数据集**：分辨率、小图放大、压缩太重、极端比例、缺标注、近重复，以及整个文件夹的画风一致性（像一位画师，还是可能混了好几种；两位画师混在一起约一半抓得到） | `audit`、`duplicates` |
| **量化画风与偏好**：两组图是否同一画风、差在哪里（亮度、鲜艳度、线条量等）、用你自己的喜欢/不喜欢训练的个人偏好模型（不是通用美学分数；一个人实测 AUC 约 0.77；遇到没评过的画师、换了生成来源都会明显变差，适合粗筛） | `compare`、`taste`、网页界面的外观描述与“喜欢/不喜欢” |
| **补新图进已分好的数据集**：一批新图各自该放哪一组、哪些和数据集里的图重复、哪些哪组都不像（放进 `_unsure` 让你看） | `sort` |
| **一页画风报告**：一致性、外观和 278 位画师比的位置、最像的画师、各画风组的代表图，保存为一个 HTML 文件，方便保存或传给朋友 | `report` |

## 命令行

下面的 `style-atlas ...` 命令在命令窗口里输入：程序文件夹里双击 `Style Atlas console.bat`（Linux：`./style-atlas-cli.sh <命令>`）；从源代码运行时用 `scripts\StyleAtlas-console.bat`。

### 训练 LoRA 前的建议流程

以下的 `style-atlas ...` 指令都在 `scripts\StyleAtlas-console.bat` 开的窗口里输入（一次贴一行）。

**1. 检查**：太小的图、极端长宽比、动图、缺标注或标注是空的、混在彩色图里的黑白图、黑白标签和图不一致的标注，以及只靠 EXIF 标记转正的照片（kohya 会把它横着训练）。

```bat
style-atlas audit "D:\lora\artistX" --min-side 768
```

**2. 在网页界面先看一遍**：哪些是重复图（“重复”标签页）、哪些不合群（“检查”标签页）、分组是否合理。不要的图按 X 排除。步骤 1 的检查也可以在网页做：“检查”标签页按“开始检查”。

```bat
style-atlas serve "D:\lora\artistX" --time name
```

网页开着时这个窗口会一直被占用。看完后在窗口里按 Ctrl+C 停掉，或另外再开一个 `StyleAtlas-console.bat` 窗口做下一步。

**3. 导出成 kohya 文件夹**。程序会先排除重复图（每组留分辨率最高、有标注的那张），再分组，另外放出最不合群的 5 张，最后依每组张数自动算 repeats。

> **在网页上移动、合并、拆过组或取过名的话，请直接在网页按“导出训练数据集…”，不要用下面的指令**：指令会重新分组，只沿用你按 X 排除的图。

```bat
style-atlas cluster "D:\lora\artistX" --layout kohya --name artistX --dedupe --drop-outliers 5 --export copy
```

- 步骤 2 按 X 排除的图，这里也会放进 `_excluded\`。

导出结果在数据集旁边的 `D:\lora\artistX_style_atlas\folders\`，不会写进原本的文件夹：

```
11_artistX_style01\   ← 一种画风，标注 .txt 会一起复制
20_artistX_style02\
_duplicates\          ← 没有数字前缀，kohya 会忽略
_outliers\
_unassigned\
_excluded\            ← 在网页界面按 X 排除的图
_trimmed\             ← 超过每组上限的图（有用 --max-per-group 时）
dataset_config.toml   ← kohya sd-scripts 的数据集设置（`--dataset_config`），列出每组的文件夹与 repeats
diffusion_pipe_dataset.toml ← diffusion-pipe 的数据集设置（训练设置里的 `dataset`）
onetrainer_concepts.json    ← OneTrainer 的 concepts 档（复制到 OneTrainer 的 training_concepts 文件夹再选）
ai_toolkit_datasets.yaml    ← ai-toolkit 的 datasets 段落（贴进训练设置的 datasets:）
```

- 每组的 repeats 会让“张数 × repeats”接近 100。也可以用 `--repeats 10` 固定。
- 某组图太多时，加 `--max-per-group 40`（网页：“导出训练数据集…”里的“每组最多几张”）只保留 40 张，会挑能涵盖整组变化的那些（从最典型的一张开始，每次挑和已选的最不像的一张），其余放到 `_trimmed\`。repeats 会依保留的张数重算。
- 想在同一个 LoRA 里用不同触发词叫出不同画风，可以加 `--trigger-captions`：
  - 导出的标注开头会自动加上该组名称，例如 `artistX_style01, `；
  - 原始标注不会被改。
  - 完整流程见 [docs/LORA_GUIDE.md](docs/LORA_GUIDE.md)。
- 想把描述画风本身的标签（例如 `sketch`、`monochrome`）从导出的标注拿掉，让触发词去学这个画风：加 `--strip-tags "sketch, monochrome"`（网页：“导出训练数据集…”里的“要移除的标签”）。只比对完整标签，原本的标注不会被改。

  ```bat
  style-atlas cluster "D:\lora\artistX" --layout kohya --name artistX --dedupe --drop-outliers 5 --export copy --trigger-captions
  ```
- `clusters.json` 会列出每组最常见的标注 tag，以及 tag 在这组里比整体多出几倍。例如某组特别多 `monochrome`、`sketch`，大概就是草稿那一组。
- 源文件案永远不会被移动或删除。每次导出都写到新的文件夹（`folders`、`folders_2` …），不会和上一次混在一起。
- `--export link` 改用硬链接，不占额外空间，但链接档和原文件是**同一个文件**，在导出文件夹里改标注，原本的也会一起改。不确定的话就用 `copy`。

**要把同一位画师的作品分成不同时期**：
- 用 `--granularity period`，并加上 `--time name` 看时间分布。网页界面则选“时期（单一画师）”并填段数。
- 会分成 3 段（`--k 4` 改段数；3 段只是惯例），几乎每张图都会分进其中一段。
- 草稿、截屏这类不合群的图也会被分进去，请搭配 `--drop-outliers 5`（或在网页“检查”标签页按 X 排除）。
- 少于约 100 张时，分段界线不太稳定，请在网页上确认。

**其他分组方式**：
- 默认是 `auto`，按图片自动挑阈值（最多到“中”的 0.47）。画师越多，最佳阈值越低。50~300 位画师混在一起时，auto 分出的组和真正的画师吻合得比固定的“中”好（ARI，0~1，越高越吻合：高 0.16~0.21），代价是未分组的图从 1~2% 增加到 5~9%。少数画师、或文件夹里有大量近似图时，两者差不多。
- 单一画师、风格变化很大时，auto 可能切出很多小组，这时改用 `--granularity medium` 或 `period`。
- **很多位画师混在一起的图库**（例如收集来的参考图）：用 `--granularity artists`（网页选“按画师（20 位以上的图库）”）。它在另一个专门区分画师的空间里分组：20 位画师混在一起时，分出的组和真正画师的吻合度（ARI）比 auto 高 0.13，50 位时高 0.07；只有几位画师时差不多（+0.02~0.04）。同一位画师分画风、分时期时不要用，它会把同一位画师内部的差异压小。
- `fine`/`medium`/`coarse` 是固定阈值，就是网页分组菜单的“细”“中”“粗”；`--k 3` 直接指定组数；`--threshold 0.35` 自己指定切分距离（高级，一般不用）。
- 网页界面也能选“自动”或调阈值，再按“重新分组”。

### 其他用法

**把新图分进已经分好的数据集**：数据集已经分好画风组（例如之前导出的 kohya 文件夹），又收集到一批新图 `D:\new`：

```bat
style-atlas sort "D:\new" --into "D:\lora\artistX_style_atlas\folders" --by-folder --export copy
```

- 加 `--merged` 会另外写出 `merged` 文件夹：数据集加上符合的新图，可以直接训练（kohya 的 repeats 和训练配置文件会自动更新，原本的数据集不动）。
- 每张新图会放进最像的子文件夹。不够像的放进 `_unsure`：到组中心的距离，要不超过那组七成的图（每张图量的是到“其他图”中心的距离）；和数据集里某张几乎一样的放进 `_already_in_dataset`。结果在 `D:\new_style_atlas\sorted`，`sorted.csv` 列出每张的最近组、距离和重复的对象。kohya 文件夹补图后，它也会提示新的 repeats 前缀（张数 × repeats 维持约 100）。
- 不加 `--by-folder` 时，改用数据集的画风组（网页存过的分组和名称，没有就重新自动分组；加 `--fresh` 一律重新分组）。少于 3 张的组不会放新图进去。
- 实测（工具没看过的画师，数据集是 10 位画师各一个子文件夹）：新作品放对文件夹 91.5%；被判“符合”的约 69%，其中 99% 放对；其他画师的图约 9% 被判符合（每组只有 10 张时 14%）。所以 `_unsure` 里约有三成其实是同一位画师的图，值得看一眼；`sort` 会把它们依离某一组的远近排好列出（只是参考，实测同画师的图排在别人前面约 2/3 的机会）。

**以图找图**：在图库 `D:\gallery` 里找和两张范例最像的 30 张。

```bat
style-atlas search ref1.png ref2.png --combine --in "D:\gallery" --top 30
```

想同时搜好几个图库：把它们放在同一个上层文件夹底下，`--in` 指那个上层文件夹即可（默认会往子文件夹找）。每张图算过一次就会记在缓存里（按文件内容），之后重开或换个方式搜都不用重算；第一次算很多张图时比较久（CPU 每秒约几张）。

**这张图像哪位画师？** 图库 `D:\artists` 底下每位画师一个文件夹时，列出最像的 5 个文件夹，以及每个文件夹里最像的那张：

```bat
style-atlas search mystery.png --in "D:\artists" --by-folder --top 5
```

比的是每个文件夹的整体画风（平均），不是单张最像的图：在 114 位工具没看过的 Danbooru 画师上，第一名猜中 70.7%，只看最像那张图的画师是 63.4%。

**扩充训练集**：把范例图放进一个文件夹，找出 100 张最像的，连同标注复制到 `D:\lora\more\`（文件名开头是名次，`001_` 最像；文件夹里已经有东西时，会改放到旁边新开的 `more_2`）。排序用范例的平均画风；范例有 10 张以上时，改用范例训练的小模型（在工具没看过的画师上，范例少时平均画风反而比小模型准）。

```bat
style-atlas search "D:\examples" --combine --in "D:\gallery" --top 100 --copy-to "D:\lora\more"
```

**单一 HTML 的 3D 地图**（脱机也能开，可以传给朋友）、**近重复图分组**、**最不合群的 20 张**：

```bat
style-atlas map "D:\gallery" -o gallery_map.html
style-atlas duplicates "D:\gallery"
style-atlas outliers "D:\lora\artistX" --top 20
```

**一页画风报告**：把一个文件夹的画风整理成一页：一致性、外观（例如“比 89% 的画师更亮”）、最像的画师（给 `--artists` 参考图库时）、有 3 个以上子文件夹时（例如每位画师一个）每个子文件夹最像哪两个和大致的家族、每个画风组的代表图（几乎相同的图只放一张）。网页上整理过的分组和名称会直接沿用，排除（X）的图不算在内；网页的“高级…”里也有“保存为画风报告”。

```bat
style-atlas report "D:\lora\artistX" --artists "D:\artists"
```

**画师地图**：图库按画师（或画风）分文件夹时，`--by-folder` 让每个文件夹变成地图上的一个点：位置是那个文件夹的平均画风，缩略图是它最典型的一张。靠得近的就是画风相近的画师。颜色是大致的“画风家族”，只能当参考：同一位画师的作品分两半各画一次，两次分出的家族吻合度只有 ARI 0.32。

```bat
style-atlas map "D:\artists" --by-folder -o artists_map.html
```

**两组图是否同一画风、差在哪里**：输出画风距离、两边是否很可能不同（p 值），在“两位不同画师”的分布里落在哪里（比 95% 都接近、和比较接近的那一半差不多、或比一半还远；两边各 5 张以上时，依 Danbooru 画师的实测），外观差异（例如“B 偏冷、线条多”），每边最能看出差别的图，以及合在一起训练会怎样。张数更少时改用 z 值（“差距是同一画风内部噪声的几倍”）。B 里有和 A 某张几乎一样的图时（例如 LoRA 出图重现了训练图），会逐一列出。加 `--json` 会输出全部数字（重复的图在 `b_copies_of_a`）。

```bat
style-atlas compare "D:\old_works" "D:\new_works"
```

**偏好模型**：在网页界面评过喜欢/不喜欢之后，模型会自动保存为 `<文件夹>_style_atlas\taste_model.npz`，可以拿来替新的一批图排序。也可以用两个文件夹直接训练：

```bat
style-atlas taste train --like "D:\喜欢的图" --dislike "D:\不喜欢的图" --model "D:\my_taste.npz"
style-atlas taste score "D:\new_batch" --model "D:\my_taste.npz" --copy-to "D:\先看这些"
```

训练时会列出两个 AUC（同一批画师的其他图、整组相似画风留出来；遇到没评过的画师，通常比后者再低一点），以及你喜欢的图和不喜欢的比外观上差在哪里。排序时每张会列出最像哪张评过的图，和所有评过的图都不太像的会标出来（它们的分数接近乱猜）；`--copy-to` 会把分数最高的 20 张（`--top` 可改）依名次复制到新文件夹。模型文件里存有评过的图的文件名和画风向量：把模型文件分享给别人时，对方看得到你评过哪些图。

**同样的角色出现在很多种画风里**时（例如用固定角色测试不同画师组合），请加 `--ignore-characters`，或在网页界面的“高级…”勾选“忽略角色轴”。画风特征会被角色外观（发色、服装）强烈拉走，不修正时，最接近的图常常是“同角色、别的画风”。
- 它会自动从图里找出角色（不需要标注），再拿掉角色造成的差异。角色越多越有用：4 个角色时，以图找图找对画风的比例是 70%，旧方法 `--neutralize 1` 是 58%。
- 这主要改善**以图找图**。同一个模型、固定角色的出图，画风差异通常很小，自动分组多半只会得到一组；这类文件夹请以“以图找图”为主，或用 `--k` 直接指定组数。
- **混了不同画师时不要开**：那时角色差异和画风差异分不开，分组会坏掉。
- 旧的 `--neutralize 1` 也还能用；查找图里的角色不在文件夹中时，它比较稳。详细数字见 [docs/BENCHMARKS.md](docs/BENCHMARKS.md)。

`--time name` 会从文件名推出先后顺序：Pixiv、Danbooru 作品编号和推文编号（都会随上传时间递增），或文件名里的日期（`20230512`、`2023-05-12`）；`--time mtime` 则用文件修改时间（复制或解压后常会变掉）。同一个文件夹里的文件名格式要一致，顺序才有意义。开了之后，每个画风组旁都会画出时间分布，可以看出哪种画风是早期、哪种是近期。

支持 png、jpg、jfif、webp、bmp、gif；avif 需要 Pillow 本身支持。动图只看第一格。CPU 默认最多用 8 个线程并降低优先权，不会拖垮整台电脑；`--threads 0` 可取消限制。

**指令一览**（方括号是可省略的部分；每个指令加 `-h` 会列出全部选项）：

| 指令 | 做什么 |
|---|---|
| `style-atlas serve 文件夹` | 打开网页界面（`StyleAtlas.bat` 做的就是这个） |

| `style-atlas search 范例图 --in 图库 [--combine] [--by-folder] [--copy-to 文件夹]` | 以图找图；`--by-folder` 列出最像的子文件夹（画师） |

### 网页界面与 3D 地图

- 右侧“LoRA 数据集”标签页有“① 检查数据 → ② 整理画风组 → ③ 导出”三个步骤、检查和重复的图，照顺序点就能完成训练 LoRA 前的整理。
- 缩略图浮在 3D 空间中，外框颜色代表画风组，组名浮在每组中央（右上角“组名”可关掉；最多显示最大的 16 组）。左键拖动移动地图、右键拖动转动，滚轮朝鼠标指的地方缩放；拉近时缩略图长得比间距慢，挤在一起的图会散开。双击图片看大图（← → 换下一张、Esc 关），双击空白处放大那里。`+` / `-` 调整缩略图大小。按 `?`（或右上角的 ? 按钮）会列出所有快捷键。
- 上方可以切换**分组排列**（每组排成一个岛，看得清哪张属于哪组；岛和岛的距离不代表相似度）和**真实分布**（远近照画风，压成 3D 只是大概）。
- “查看”菜单：界面大小（也可以按 Ctrl + / Ctrl −；宽屏幕会默认大一点）、圆点或缩略图、自动旋转、保存为图片、“录一圈”（把地图转一圈录成 8 秒的视频，Chrome/Edge 是 MP4，Firefox 是 WebM）、深浅色、语言。
- 点右侧的画风组，镜头会飞过去并列出成员。点地图上任一张图，会列出最接近的 12 张。
- “检查”标签页：按“开始检查”会列出太小的图、小图放大或很模糊的图、压缩很重的 JPEG、标注提到水印或签名的图、极端长宽比、混在彩色图里的黑白图、黑白标签和图不一致的标注、同一标签有下划线和空格两种写法的标注、没有标注或标注是空的图、动图、只靠 EXIF 标记转正的照片（和 `audit` 指令相同，不用打指令）；下面是最不合群的图。“重复”标签页列出近重复图组。
- “查看”菜单里的“指标轴版面”：切换后，三个轴可以各自选一种指针，缩略图会移动到对应位置。可选的指针有：
  - 偏好分数：用网页界面评过分之后才有。
  - 离参考集距离（原创度）：要先指定已知画风的文件夹（例如画师作品或论坛配方）。在网页的“高级…”填路径、按“加载参考”即可（第一次会嵌入里面的图），或启动时加 `--reference 文件夹`。
  - 时间。
  - 离群度。
  - 外观测量：亮度、对比、鲜艳度、冷暖、线条量、平涂度（见下一节）。例如 X 选冷暖、Y 选线条量、Z 选鲜艳度，就能看到整个文件夹在这三个面向上怎么分布。
- 右侧每个画风组的卡片下方，会用一句话说明这组和整个文件夹相比的外观差异，例如“偏冷、线条多、色彩鲜艳”。文件夹底下有子文件夹（例如每位画师一个）时，还会列出这组主要“来自”哪些子文件夹；同一个子文件夹被分成两组时（同一位画师的不同画风或时期）也会提醒。
- 上方的筛选框可以打文件名，或打 `#` 加标注里的标签（例如 `#monochrome`、`#sketch`），只亮出那些图；配合 Shift 拖框可以一次排除。
- 每组的卡片会列出“最接近”的 3 组（括号里是画风距离），点一下就跳过去；想合并相近的组时很方便。
- 打开一组后，用“和…比较”选另一组，会列出两组的画风距离、差异是否明显，以及外观差在哪里（和 `compare` 指令相同）。
- 只有网页界面才有的功能：
  - 拖一张图进画面就能以图搜索。一次拖多张同一种画风的图，会当成同一种画风一起搜索（用它们的平均画风；10 张以上时改用它们训练的小模型排序）。
  - 一次拖多张时，还会告诉你这批图有几张“和这个文件夹里某一组的画风够接近”，例如拿 LoRA 算出来的图检查像不像训练集，或新找到的图该不该加进来。请看整批的比例：实测同一画师没用到的作品约 61% 落在范围内，其他画师约 1%。
  - 画风渐变：选一张图按“画风渐变：从这张开始”，再选另一张按“画风渐变：到这张”，会列出在画风上从前一张渐变到后一张的一串图。适合找两种画风之间的过渡风格。
  - 调阈值后重新分组。按“导出训练数据集…”会打开导出对话框：左边勾要导出的组，右边选每组各一个 LoRA 或合成一个、名称、存放位置、一般文件夹或 kohya 格式（更多选项里有每组最多几张、要移除的标签、“标注加触发词”、“统一标签写法”）；会写出哪些文件夹、各几张随勾选实时显示，按“导出 N 张”开始。“忽略角色轴”和参考文件夹放在“高级…”里。
  - 按“导出时排除”（键盘 X）手动剔除不要的图，清单会保存，导出时放到 `_excluded\`。
  - 一次处理很多张：按住 Shift 点图（地图或清单里都可以），或按住 Shift 在地图上拖一个框，选好后用上方的“排除这 N 张”或“移到其他组…”一次完成；移动算一步，可以撤销。Esc 清除选中。
  - 文件夹里混了别的画师的图时：先把看到的两三张按 X 排除，再到“检查”标签页的排除清单按“找更多像这些的”，其余的通常都会排在最前面（实测：3 张当范例时，前 30 名找回 98%）。
  - 手动修正分组，修正会反映在之后的导出：
    - 选中一张图，用“移到其他组…”把它改放到别组；
    - 打开一个组，用“把这组合并到…”选好目标，再按出现的“把 A 合并到 B”才会合并；或按“拆成两组”。
    - 打开一个组按“找更多像这组的”，会列出不在这组里、但最像它的图（组有 10 张以上时用这组的图训练的小模型排序，较少时用这组的平均画风），方便把被分错或没分到的图找回来。
    - 打开一个组，在“取名”栏输入名字并按 Enter，例如“早期”“线稿期”。导出时文件夹与触发词会用这个名字，像是 `10_artistX_早期`。
    - 修正、名称和“忽略角色轴”开关会自动存到 `<文件夹>_style_atlas/groups.json`，下次打开同一个文件夹时会还原（开关以网页上最后的状态为准）。
    - 名称跟着图走：移动、合并、拆组或重新分组后，名称会留在包含原本大部分图的那一组；合并时以被并入的那组的名称为准。
    - 按错了可以按“撤销”或 Ctrl+Z，最多可退回 30 步。“重新分组”会清除手动修正，但同样可以撤销。
  - 图片有标注 `.txt` 时，每个画风组下面会列出这组特别常见的标签（例如“sketch, white background”），方便一眼看出这组是什么。
  - 用“喜欢/不喜欢”（键盘 L / D）评图。各评满 5 张后，“偏好”标签页会用你的评分训练模型，替还没评的图排序，并显示交叉验证的 AUC。
  - 按“评下一张最有用的图”可进入评分模式：只要一直按 L/D，系统会自动挑下一张和已评过的最不像的图。用一位用户的 140 笔真实投票模拟，这样评 10 张就能达到随机挑约 25 张的水准。
  - 点地图上的图，详情会显示这张图标注文件里的标签；在“替这张图加备注”打一句话按 Enter，地图上那张图旁边就会显示（例如“金发贵族系列”），方便把探索到的东西指给别人看。
- 网页界面的“保存为分享用地图”会把目前的分组、手动调整、名称和备注保存为同一种单个 HTML 文件（在 `<文件夹>_style_atlas\map.html`），完成后会显示文件大小；超过 10 MB 时，有些聊天软件（例如 Discord 免费账号）传不了，用 `style-atlas map --thumb 64` 可以存出较小的档。
- `map` 生成的是单个 HTML 文件，three.js 和缩略图都已内嵌，脱机也能开。**分享地图等于分享这些缩略图。**
- `serve` 只监听本机 127.0.0.1，会检查 Host 标头，也只提供扫描过的文件，不会把你的文件夹开放到网络上。

### 外观测量：画风“哪里不同”

在网页界面，每个画风组的卡片下方会有一句外观描述（例如“偏冷、线条多”）；把右上角的“版面”切到“指标轴”，可以用下面六项当 X/Y/Z 轴。

画风特征只告诉你两种画风差多远，没说差在哪里，所以每张图另外算 6 个看得懂的图像统计（缩到长边 256 px 后计算）：

| 测量 | 意思 |
|---|---|
| 亮度 | 整体明暗（0 全黑到 1 全白） |
| 对比 | 明暗差异的大小 |
| 鲜艳度 | 0 是黑白，越大越鲜艳，约 0.4 是霓虹色 |
| 冷暖 | 负的偏冷（蓝）、正的偏暖（红橙） |
| 线条量 | 线条多寡：线稿、排线、细纹理越多越高 |
| 平涂度 | 平涂面积多寡：赛璐璐平涂、素色背景越多越高 |

- 用在哪里：网页的组卡片文字和“指标轴”、`clusters.csv`（每张图一栏一个测量）、`clusters.json`（每组和整个文件夹相比的差异与文字）、`compare`（B 减 A，单位是两组合并的标准差）。
- 每张图只算一次，结果存在缓存里；之后新嵌入的图在嵌入时顺便算，不必再读一次档。旧版就嵌入过的图，第一次会补算（实测约每秒 70 张 832×1216 的 PNG，1 万张约 2~3 分钟）。
- 单张图的数值噪声大，请比较**组的平均**。在 306 位画师、3,259 张 Danbooru 作品上，各测量有 13~40% 的差异来自“画师不同”（线条量 0.40、平涂度 0.37、鲜艳度 0.32、亮度 0.32、对比 0.26、冷暖 0.13），其余来自同一画师的不同作品（场景、构图）。冷暖最受场景影响。
- 这些是图像统计，不是美感分数：“线条多”不代表比较好。
- 长边小于 256 px 的小图会被误判成“线条多、平涂少”，比较时请用尺寸差不多的图。大图之间的尺寸差异则几乎没有影响。

### ComfyUI 节点（实验性）

`comfyui/` 文件夹里有三个节点，可以把画风检查直接接进生成流程：

- **Load Style References**：读一个文件夹当参考集，例如画师作品、以前生成过的图、论坛配方的成品。
- **Style Distance**：计算每张生成图离参考集多远，并列出最接近的是哪一张。
- **Style Gate**：只让够原创的图通过（keep original），或只让够像的图通过（keep matching）。

安装步骤（两步都要做）：
1. 在 ComfyUI 自己的 Python 里安装本工具，例如 `python_embeded\python.exe -m pip install -e <repo 路径>`。节点的代码在这个套件里。
2. 把 `comfyui` 文件夹复制或链接到 `ComfyUI\custom_nodes\style-atlas`。这个文件夹只是让 ComfyUI 找到节点的入口。

Style Gate 的默认阈值是 0.5。在 Danbooru 上，单张图之间的距离，同画师的中位数约 0.40，不同画师约 0.56。

（节点已在 Python 里用真正的 CSD 模型跑过；还没装进实际的 ComfyUI 测试。）

## 从源代码运行（开发者）

### Windows（从源代码）

1. 安装 [Python 3.10 以上](https://www.python.org/downloads/)（3.10~3.14 都有自动测试），安装时勾选“Add python.exe to PATH”。也可以在命令提示符运行 `winget install -e --id Python.Python.3.12`。
2. 下载本项目：在 GitHub 项目页面按 **Code → Download ZIP** 再解压，会用 git 的话也可以 `git clone`。然后双击 `scripts\setup.bat`。它会在项目文件夹里创建 `.venv`，检测到 NVIDIA 显卡就装 CUDA 版的 torch（下载约 2.5 GB），没有就装 CPU 版（约 200 MB），再安装本工具。
3. 双击桌面上的 **Style Atlas**（`setup.bat` 最后会创建这个快捷方式），在程序里按“打开图片文件夹…”，或直接把文件夹拖进窗口。程序会先显示准备进度（第一次会先下载 2.4 GB 的模型，接着计算每张图的画风），算好后自动变成地图。开过的文件夹会列在开始页面，下次点一下就好。地图左上角的“← 开始页面”关掉这个文件夹、回到开始页面；“新窗口”在另一个窗口开别的文件夹，两个可以同时开着。程序开着时再按一次桌面快捷方式，也会开一个新窗口。关掉窗口就是关掉那个文件夹，最后一个窗口关掉时程序就结束。
   想用浏览器开也可以：照旧把图片文件夹拖到 `scripts\StyleAtlas.bat` 上（或双击它再选文件夹）。

Windows 跳出“Windows 已保护你的电脑”时，按“更多信息”→“仍要运行”。

**更新到新版**：下载新的 ZIP，解压后**直接覆盖**到原本的文件夹（保留里面的 `.venv`），再双击一次 `scripts\setup.bat`。torch 已经装过，不会重新下载，几十秒就好。用 git 的话是 `git pull` 再跑一次 `setup.bat`。分析结果（每个图片文件夹旁边的 `_style_atlas` 文件夹）和向量缓存都不会受影响。新版做了什么见 [CHANGELOG.md](CHANGELOG.md)。

想先试试看：双击 `scripts\StyleAtlas-demo.bat`（或运行 `style-atlas demo`），会生成 72 张四种风格的范例图并直接打开网页。

**要打指令时**（下面的 `audit`、`cluster`、`search` 等），请双击 `scripts\StyleAtlas-console.bat`，它会开一个已经设置好的命令窗口，在里面输入指令即可。直接开一般的命令提示符打 `style-atlas` 会出现“不是内部或外部命令”，因为工具装在 `.venv` 里。

不确定环境有没有装好时，可以在这个窗口运行 `style-atlas doctor`，它会检查 Python、torch、有没有抓到显卡、模型是否已下载、磁盘空间。

**第一次使用会遇到的事**
- 开着网页界面时，**不要关掉黑色的命令窗口**，关掉网页就停了。浏览器没自动打开的话，手动开 `http://127.0.0.1:8770`（端口号被占用时会往后找，以窗口里印出的网址为准）。
- 标注文件请放在图片旁边、同文件名的 `.txt`（例如 `001.png` 配 `001.txt`），导出时会一起复制。子文件夹里的图也会一起读进来，不要的话加 `--no-recursive`。
- 建议先拿 100 张左右的文件夹试一次（只用 CPU 约半分钟；第一次另外要下载模型），熟悉流程后再跑大量的图。

**几个名词**
- **kohya 格式**：kohya_ss/sd-scripts 训练 LoRA 用的文件夹结构，文件夹名称像 `10_artistX_style01`，开头的数字是 repeats。
- **repeats**：每个 epoch 里这个文件夹的图要重复几次。张数少的组 repeats 高一点，各组的份量就会接近。
- **触发词（trigger word）**：写在标注最前面的词，训练后在提示词里写它就能叫出这种画风。

**第一次分析前**，程序会从 Hugging Face 下载 CSD 模型，只会下载一次。下载的 2.4 GB 源文件放在 `%USERPROFILE%\.cache\style-atlas`，另保存为 1.2 GB 的精简文件后就删掉；所以第一次需要约 3.9 GB 的空间，之后只占 1.2 GB。空间不够时，程序会在下载前就说明。C 槽空间不够时，可以先设置环境变量 `STYLE_ATLAS_CACHE`（例如 `D:\style-atlas-cache`），源文件和精简文件都会改存到那里。如果你自己设置了 `HF_HOME` 或 `HF_HUB_CACHE`，源文件会放在那里，不会自动删除；`style-atlas doctor` 会提示它已经用不到了。连不上 Hugging Face 时（例如在中国大陆），先设置环境变量 `HF_ENDPOINT=https://hf-mirror.com` 改从镜像站下载。同一个文件夹也存放向量与缩略图缓存（每张图约几 KB），删掉不影响源文件案，之后会重新生成。网页界面会在准备页上显示下载和计算的进度；其他指令的进度印在黑色窗口里，下载时可能停很久，这是正常的。

速度参考：只用 CPU 时，8 线程约每秒 2.5–4 张，1,000 张约 4–7 分钟（实测，大图较慢）。有 NVIDIA 显卡通常会快很多，但这点没有实测过。每张图的向量都会缓存，第二次开同一个文件夹就不用重算向量。

### 手动安装

不想用 `setup.bat` 时，可以自己建虚拟环境。有 NVIDIA 显卡时，请在 `pip install -e .` 之前先依 pytorch.org 的说明装好 CUDA 版 torch。最后一行是选用的（地图改用 UMAP 版面）。

```bat
git clone https://github.com/Rinne414/style-atlas
cd style-atlas
python -m venv .venv
.venv\Scripts\activate
pip install -e .
pip install -e ".[umap]"
```

装在 `.venv` 里，所以 `StyleAtlas.bat`、`StyleAtlas-console.bat` 都能直接用；自己开命令窗口时，先运行 `.venv\Scripts\activate`。找不到 `style-atlas` 指令时（Python 的 Scripts 文件夹不在 PATH），改打 `python -m styleatlas`，后面接一样的参数。
