# 用 style-atlas 整理画风 LoRA 数据集

这是一份实务流程，每一步附上工具的指令。第 5 节的建议来自网络文章（2026-10 查阅），不是本工具的测量结果，请自行判断是否适用你的模型。

下面的指令请在 `scripts\StyleAtlas-console.bat` 开出的窗口里输入，一次贴一行。步骤 2 也可以改成把文件夹拖到 `scripts\StyleAtlas.bat` 上直接开网页界面；步骤 1、3 的指令则一定要在 console 窗口里打。

## 1. 先检查

```bat
style-atlas audit "D:\lora\artistX" --min-side 768
```

不想打指令的话，可以直接进步骤 2：网页的“检查”标签页按“开始检查”会列出同样的问题。

修掉或移除下列几类图：

- 太小的图：短边小于训练分辨率。从 Danbooru、Pixiv 下载的图常是缩小过的 sample 版（短边只有几百 px），能的话改用原图；一半以上都太小时，`audit` 会直接提醒。
- 小图放大或很模糊的图：LoRA 会把模糊也学进去。这种图在画风地图上和原图几乎同一点，分组找不到，只有这项检查会列出。用 AI 放大过的图通常不会被列出。检查时会先把图缩到训练尺寸（约 1024×1024）再看，缩小后仍清晰的图（例如大画布上柔和的笔触）不会被列出。
- 压缩很重的 JPEG（质量低于 70）：质量 60 以下的 JPEG 会让画风判断明显失准，能找到原图就换成原图。
- 长宽比极端的图。
- 截断的文件。
- 动图。
- 只靠 EXIF 标记转正的图（多半是手机拍的照片）：看图软件和本工具会按标记转正，但 kohya sd-scripts 读的是保存时的方向，会把它横着或倒着训练。用本工具导出（`--export` 或网页的“导出”）时会自动把它转正后存出，原文件不动；直接拿原文件夹训练的话，要先用看图软件转正后另存。ai-toolkit 和 OneTrainer 会自己转正，不受影响。
- 缺标注或标注是空的。全部都没有标注也能训练画风 LoRA：kohya 会改用文件夹名称里的触发词（见步骤 3）。要标注的话，先用 WD14 tagger 之类的工具生成；style-atlas 不会生成标注。
- 另外会列出**出现在一半以上标注的标签**和比例（例如 `1girl 95%、white shirt 87%`）。几乎每张训练图都有的内容（同一个角色、同一套衣服）会和画风一起被学进去；如果它不是画风本身，补一些不含它的图。
- 同一个标签在数据集里有两种写法（有的 `long_hair`、有的 `long hair`）：文字编码器会当成两个不同的词，标签的意思就被拆开了。列出的是用了少数写法的标注，改成和其他标注一致；或在导出时加 `--fix-tag-spelling`（网页：“统一标签写法”），导出的副本会统一成多数标注的写法，原始标注不动。
- 标注里有 `watermark`、`signature`、`artist name`、`web address` 这类标签的图：图上有水印或签名，LoRA 会一起学进去。可以裁掉、排除，或把那个标签留在标注里（让模型把它归给那个标签，而不是画风）。
- 混在彩色图里的黑白图（例如草稿、漫画页）。整个文件夹大多是黑白时不会列出，因为那是画师本身的风格。
- 其中标注没有 `monochrome` 或 `greyscale` 的黑白图：LoRA 会把“黑白”当成触发词画风的一部分。补上标签或排除。Danbooru 上约 15% 的黑白图也漏了这两个标签，所以从 Danbooru 抓来的标注也要看。
- 标注写 `greyscale`、图却明显有颜色（例如裱框照片、局部上色、带色调的草稿）：改成 `monochrome` 加上颜色标签，或拿掉 `greyscale`。只有 `monochrome` 的单色图不会列出，那本来就对。

## 2. 看一遍，再决定怎么分

先看“检查”标签页最上面的**画风一致性**（`cluster` 指令也会印出来）。注意：分出好几组不代表混了不同画师，单一画师的 20 张图约三分之二也会分成 2 组以上（子画风、时期）；要判断有没有混到别的画师，看的是一致性：比 90% 的单一画师还分散时，文件夹可能混了不同画风或时期，值得分组看看、必要时分开训练。两位画师混在一起时大约一半抓得到，三位约 85%，五位都抓得到（另外约 11% 的单一画师会被误判）；同一个模型、同样角色的 AI 出图则会显得很一致，不适用。

```bat
style-atlas serve "D:\lora\artistX" --time name
```

在网页界面里依次看这几页：

- **重复**：同一张图、裁切、表情差分、同场景连续画面。重复图会让模型过度学那一张。
- **检查**：上方的“开始检查”会列出步骤 1 的问题图（和 `audit` 相同），下方是草稿、漫画页、截屏这类通常不合群的图。不要的按 X 排除。
  - 混进了别的画师的图（例如抓 tag 时抓到的）：它们彼此很像，不一定会出现在不合群清单里。先把看到的两三张按 X 排除，再按排除清单上方的“找更多像这些的”，其余的通常都会排在最前面，逐一点击后按 X。
- **画风组**：每组旁边的时间分布，可以看出哪一组是早期、哪一组是近期；有标注时还会列出这组特别常见的标签。
  - 默认的阈值是“自动”，会按图片决定。想按时期拆，把左下的分组菜单切到“时期（单一画师）”，在旁边填要分几段（默认 3），再按“重新分组”。几乎每张图都会分进其中一段，连草稿这类不合群的图也会，所以先在“检查”标签页把不要的按 X 排除。图少于约 100 张时，分段界线不太稳定。
  - 分错的图可以手动移到别组、合并两组，或把一组拆成两组。改错了按“撤销”或 Ctrl+Z。
  - 要处理很多张时，按住 Shift 点图或在地图上拖框选中，再一次排除或移到别组。
  - 打开一组按“找更多像这组的”，可以把被分到别组或没分到的同类图找回来。
  - 帮每组取名（例如“早期”“线稿期”），导出的文件夹和触发词就会用这个名字。
- **扩充数据集**（选用）：手上只有十几张某种画风的图时，可以用 `style-atlas search 范例文件夹 --combine --in 大图库 --top 100 --copy-to 输出文件夹` 从大图库里找出更多同风格的图。
- **偏好**（选用）：在评分模式下一直按 L/D，评约 10 张就能得到粗略的偏好排序。

网页开着时，这个 console 窗口会一直被占用。看完后按 Ctrl+C 停掉，或另开一个 `StyleAtlas-console.bat` 窗口做步骤 3。

## 3. 导出成 kohya 文件夹

```bat
style-atlas cluster "D:\lora\artistX" --layout kohya --name artistX --dedupe --drop-outliers 5 --export copy
```

- **在网页上做过移动、合并、拆组或取名时，请改用网页的“导出文件夹”**（选 kohya、填“LoRA 名称（文件夹名）”，必要时勾“标注加触发词”）：只有它会用到这些手动修正。上面的 `cluster` 指令会重新分组，只沿用你按 X 排除的图（放进 `_excluded\`）。
- 每组会导出成 `<repeats>_artistX_styleNN\` 文件夹（取过名的组用名字），标注文件一起复制。
- 文件名带有时间（Pixiv、Danbooru 作品编号、推文编号，或 `2023-05-12` 这种日期）时，用 `--granularity timeline --time name`：按时间顺序，在画风变化最大的地方切成 3 个连续的时期（`--k` 改段数；切点放在变化最大处，所以各时期的张数不会平均，例如 9、7、44 张），再用两个检验告诉你是哪一种情况：
  - **没找到和时间的关系**：这些时期可能只是任意切点，合在一起训练比较稳妥。作品少时只看得出大的变化，所以这不代表画风完全没变。
  - **只有渐变**：画风随时间改变，但没找到明确的转折点，切点可能只是把连续的变化切开。通常合在一起训练即可；想要某个时期的画风，就只留那一段。作品不到约 100 张时，幅度不大的单一转折也可能落在这里。
  - **有转折**：变化比随时间平滑变化的曲线更突然，分开训练有道理。
  - 去掉近重复后作品太少（3 段时少于 30 张）时不做检验，请直接看图。

  实测 14 位 Danbooru 画师：1 位有转折、5 位只有渐变、6 位没找到和时间的关系、2 位太少；有 6 位的 p 值在边缘，会注明往哪一边偏，例如“有一点和时间有关的迹象，但不够确定”（docs/BENCHMARKS.md）。连续发表的相似作品（一个系列）只算一次。大多数画师是渐变，所以通常一个 LoRA 就够。段数换很多种试，总有一种会碰巧显示“有转折”，请以一开始选的段数为准。

  决定训练一个 LoRA 时，把 `--granularity timeline` 换成 `--k 1` 再导出一次，全部作品会放进同一个文件夹（指令结束时也会提醒）。默认的自动分组常把一位画师分成好几组（大多只是同一画风里的细部差异），想要一个文件夹时一样加 `--k 1`。
- 指令最后会印一行张数明细（例如“共 60 张：44 张在 1 个画风文件夹；另外放：_duplicates 11, _outliers 5”），说明每张图去了哪里。repeats（文件夹名称前面的数字）是自动算的：让每个文件夹每个 epoch 约 100 张，张数少的文件夹重复较多次；要自己指定就加 `--repeats N`。
- 没有时间信息、或想纯粹按画风拆时，用 `--granularity period --time name`（`report` 加 `--time name` 也会在每组标出时间位置，方便保存或传给别人）。指令会在每组后面印出它在作品时间轴上的位置，例如 `when 9% [3%-28%]` 表示这组的中位数落在最早的 9%（中间一半落在 3%~28%），一看就知道哪组是早期、哪组是近期。
- repeats 会自动调成“张数 × repeats ≈ 100”，也可以用 `--repeats N` 指定。例如某组 20 张 → repeats 5，每个 epoch 这组看 100 次；batch size 1 时就是 100 步，训练 10 个 epoch 是 1,000 步。张数少的组 repeats 高，各组份量就接近。导出完网页和 `cluster` 指令都会直接告诉你每个 epoch 约几步。
- 某组太多张（例如 300 张）时，加 `--max-per-group 40`（网页：“每组最多几张”）只保留 40 张能涵盖整组变化的图，其余放到 `_trimmed\`。
- 导出文件夹里会一起写一份 `dataset_config.toml`（kohya sd-scripts 用 `--dataset_config` 指定），列出每组的文件夹路径与 repeats；有勾触发词时会设 `keep_tokens = 1`，让触发词在打乱标签时固定在最前面。分辨率与 batch size 请按模型自行调整（SDXL/Illustrious/Anima 用 1024）。
- 用其他训练器时：同一个文件夹还有 `diffusion_pipe_dataset.toml`（diffusion-pipe：在训练设置的 `dataset` 填这个文件；在 WSL 里要把 `D:\` 改成 `/mnt/d/`）和 `onetrainer_concepts.json`（OneTrainer：复制到 OneTrainer 的 `training_concepts\` 文件夹，再到 concepts 标签页的下拉菜单选它），以及 `ai_toolkit_datasets.yaml`（ai-toolkit：把里面的项目贴到训练设置的 `datasets:` 底下）。四份的文件夹与 repeats 都一样。
- 标注里有描述画风本身的标签（例如 `sketch`、`monochrome`）时，加 `--strip-tags "sketch, monochrome"`（网页：“要移除的标签”）把它们从导出的标注拿掉，让触发词去学这个画风。原本的标注不会被改。
- 被排除的图放在 `_duplicates\`、`_outliers\`、`_unassigned\`、`_excluded\` 这几个文件夹。它们没有数字前缀，所以 kohya 不会拿来训练。
- 每次导出都会在输出文件夹写一份 `clusters.csv`：每张图一列，`folder` 栏写它去了哪个文件夹。去了 `_duplicates`、`_outliers`、`_excluded`、`_trimmed`、`_unassigned` 的，文件夹名称就是原因，可以用试算表核对。
- 之后**又加了新图**：照样用 `StyleAtlas.bat` 打开同一个文件夹。之前的取名、移动、合并和排除都会保留，新图先放在“未归类”。点开“未归类”按“各自放进最像的画风”，够像的会自动放进最像的组（和 `sort` 同一套规则，可以撤销）；剩下的手动移，或按“重新分组”。
- 新图放在**另一个文件夹**、想直接分进已导出的文件夹：`style-atlas sort "D:\new" --into "D:\lora\artistX_style_atlas\folders" --by-folder --export copy`。每张会放进最像的那组（例如 `10_artistX_style01\`），不够像的放 `_unsure\`，和数据集重复的放 `_already_in_dataset\`，再把它们搬进对应文件夹即可。数据集是用 `--trigger-captions` 导出的话，`sort` 也加 `--trigger-captions`，放进去的新图标注开头会加上同一个触发词。实测同画师的新作品约 69% 会被判符合（其中 99% 放对组），其他画师约 9%；每组只有 10 张左右时，其他画师会到 14%，记得看一下各组新放进的图。文件夹是 kohya 格式（例如 `10_artistX_style01`）时，`sort` 会顺便告诉你补图后要改成几 repeats（例如改名成 `7_artistX_style01`），让每组每个 epoch 的份量维持在约 100；训练配置文件（`dataset_config.toml` 等）里的 repeats 也要跟着改。
- 不想自己搬：加上 `--merged`（要搭配 `--by-folder`），会另外写出 `merged\`，也就是“数据集 + 符合的新图”，可以直接拿去训练：kohya 文件夹的 repeats 会自动改好、训练配置文件也会重写；网页界面排除的图放在 `_excluded\`；原本的数据集完全不动。`_unsure\` 里的图仍要自己看：`sort` 会把它们按“离某一组多近”排好列出来（括号里是最近的组），但这只是参考，实测同画师的图排在别人前面的概率约 2/3。看完再用 `style-atlas audit` 检查 `merged\`。
- 想**一组训练一个 LoRA**（例如早期、近期画风分开）：把那一组的文件夹单独当 train_data_dir。
- 想**同一个 LoRA 里分成几个概念**：保留全部文件夹，并让每组有自己的触发词。注意两点：
  - kohya 只有在**没有标注文件**时，才会拿文件夹名（`artistX_styleNN`）当标注。
  - 有标注文件时，要把触发词写进每个标注的开头（可搭配 `keep_tokens`）。加 `--trigger-captions` 会自动帮你做：
    - 导出的每个标注开头会加上 `artistX_styleNN, `；
    - 没标注的图会新建一个只含触发词的标注；
    - 原始标注不会被改；标注原本就有的标签（例如你自己的 `artistx`）会保留在后面，但只有第一个触发词会被 `keep_tokens = 1` 固定；
    - 导出后会列出写进去的触发词。组名是中文时触发词也会是中文，SD 1.5、SDXL 的文字编码器对中文支持差，会提醒你组名改用英文。

## 4. 训练完之后

- 想要一页可以保存或传给别人的检查结果：`style-atlas report "D:\lora\artistX" --renders "D:\lora\test_renders"`。报告最前面是“LoRA 出图检查”：画风距离（和 `compare` 一样，放在“两位不同画师”的分布里看）、有几张落在训练集某一组的范围内、外观差在哪里（例如“偏冷、线条多”），以及每张出图的列表：先列可能背下训练图的（附相似度和那张训练图），再列不在训练集画风范围内的，最后是在范围内的，每张旁边都有最像的训练图。出图最好 8 张以上，才会判断整批。
- 用 LoRA 算一批图（10 张以上，主题尽量多样），整批拖进网页界面。画面会告诉你这批图有几张“和这个文件夹里某一组的画风够接近”：实测同一画师没用到的作品约 61% 会落在范围内，其他画师约 1%，所以看整批的比例，不要看单张。
- 同一个画面会另外列出“和文件夹里的某张几乎一样”的图（同一张图、裁切或调色等级的相似）。LoRA 生成的图出现在这里，代表它可能背下了那张训练图（过拟合），可以降低 repeats 或 epoch，或检查那张图是不是重复太多次。
- 想要一个数字：`style-atlas compare "D:\lora\artistX" "D:\lora\test_renders"` 会给画风距离和它在“两位不同画师”里的位置（每边 5 张以上时；更少时给 z 值），以及外观差在哪里（例如“偏冷、线条多”），并逐一列出和某张训练图几乎一样的出图（`--json` 输出全部数字）。

## 5. 一般实务建议（非本工具的测量结果）

- **张数**：画风 LoRA 的常见建议是 15–30 张就够，超过约 50 张效果递减，8–15 张可以先试。画风要一致，主题（角色、场景、构图）反而要多样。
  - 来源：https://help.scenario.com/en/articles/training-a-style-lora 、https://apatero.com/blog/ultimate-guide-lora-training-2025
- **标注写内容，不写画风**：标注描述画了什么，画风交给 LoRA 去学。2026 年有一篇研究特地把标注改写成只描述客观内容，因为描述画风的字眼会混进标注里，模型就不会把画风学给触发词。
  - 来源：https://arxiv.org/pdf/2603.16649
  - Illustrious 一类模型可以用 Danbooru 式 tag：https://offlinecreator.com/guide/illustrious-lora-training-guide
  - 本工具不生成也不改写标注内容（`--strip-tags`、`--trigger-captions` 只动导出的副本），标注请按你的模型惯例准备（Danbooru 标签或自然语言句子）。
- **kohya 的 repeats 与标注选项**：文件夹前缀 `N_name`（或 TOML 的 `num_repeats`）决定 repeats；`shuffle_caption` 与 `keep_tokens` 是常用的标注选项。
  - 来源：https://www.mintlify.com/kohya-ss/sd-scripts/quickstart
- **其他过滤工具**：deepghs 的 imgutils/waifuc 能滤掉单色图、漫画页、多角色图，也能用 CCIP 认角色，可以和本工具搭配使用。
  - 来源：https://github.com/deepghs

## 6. 要知道的限制

- 2~5 位画师混在一起时，分组和画师的吻合度约 ARI 0.5（ARI 0~1，1 表示完全吻合）；画师越多越低（50 位时约 0.38）。同一画师拆时期时，“时期”（分 3 段）和发表时间的吻合度明显比默认的自动阈值好，但整体仍偏弱（13 位测试画师的平均吻合度 AMI 约 0.12，0 是乱分、1 是完全对上）；作品少时分段结果不太稳定。所以分组是**初步整理**，请在地图上确认。
- 同一个角色出现在很多画风时，画风向量会被角色外观拉走。遇到这种收藏可以加 `--ignore-characters`（或在网页“高级…”勾选“忽略角色轴”）；但不要用在混了不同画师的文件夹。
- 近重复阈值刻意设得保守（0.95）。在 0.92~0.95 之间，常常是同角色换了姿势的不同图，对训练来说那是有效的图。

详细数字见 [BENCHMARKS.md](BENCHMARKS.md)。

## 7. 指令输出的语言

中文 Windows 上，`cluster`、`sort` 等指令的主要消息（分组结果、一致性、导出、补新图的摘要、计算进度）会自动用中文；想看英文就先运行 `set STYLE_ATLAS_LANG=en`（反过来 `zh` 强制中文）。`audit` 的项目名称会在后面附上中文（例如 `no_caption（没有标注文件）`）；其他指令的消息、选项错误和 `--help` 说明也都有中文。下表是英文消息（非中文系统，或设了 `STYLE_ATLAS_LANG=en`）的意思；中文系统上，大多数本来就会直接显示中文：

| 输出 | 意思 |
|---|---|
| `5 styles, 2 unassigned (agglomerative, cut 0.47 (auto))` | 分成 5 组，2 张没有分进任何组；切分距离 0.47 是自动选的 |
| `style consistency: spread 0.74, more spread than 64% of single artists` | 画风一致性：比 64% 的单一画师分散（越高越可能混了不同画风） |
| `(few images)` | 这组张数少，训练时可能不够 |
| `[brighter, less colourful, more line work]` | 这组和整个文件夹比：偏亮、色彩淡、线条多 |
| `when 9% [3%-28%]` | 这组在作品时间轴上的位置：中位数在最早的 9%（加 `--time name` 才有） |
| `one epoch = 400 steps at batch size 1` | batch size 1 时，每个 epoch 约 400 步 |
| `note: style 03 kept too few images ...` | 第 3 组的图都被当成重复或离群而拿掉，所以没有文件夹（编号跳过） |
| `N near-duplicates set aside before grouping` | 有 N 张近重复图先放到一边，不参与分组 |
| `_unsure`、`_already_in_dataset`（`sort`） | 不够像任何一组；和数据集里的某张几乎一样 |
| `X% fit their group: mostly the dataset's styles` | 新图有 X% 符合某一组：大多是数据集的画风 |
| `smaller_than_min_side`、`no_caption`、`soft_or_enlarged`（`audit`） | 短边太小、没有标注文件、像是放大过的图 |
| `low_jpeg_quality`、`watermark_or_signature` | JPEG 压缩太重、标注里提到水印或签名 |
| `buckets (kohya, 1024)` | 图片会分进哪些 kohya 长宽比 bucket，各几张 |
| `ranked by style match in the search space ...`（`search`） | 名次按画风相似度排序；旁边的数字是一般的相似度，所以不一定按大小排 |
