# 用 style-atlas 整理畫風 LoRA 資料集

這是一份實務流程，每一步附上工具的指令。第 5 節的建議來自網路文章（2026-10 查閱），不是本工具的測量結果，請自行判斷是否適用你的模型。

下面的指令請在 `scripts\StyleAtlas-console.bat` 開出的視窗裡輸入，一次貼一行。步驟 2 也可以改成把資料夾拖到 `scripts\StyleAtlas.bat` 上直接開網頁介面；步驟 1、3 的指令則一定要在 console 視窗裡打。

## 1. 先檢查

```bat
style-atlas audit "D:\lora\artistX" --min-side 768
```

不想打指令的話，可以直接進步驟 2：網頁的「檢查」分頁按「開始檢查」會列出同樣的問題。

修掉或移除下列幾類圖：

- 太小的圖：短邊小於訓練解析度。從 Danbooru、Pixiv 下載的圖常是縮小過的 sample 版（短邊只有幾百 px），能的話改用原圖；一半以上都太小時，`audit` 會直接提醒。
- 小圖放大或很模糊的圖：LoRA 會把模糊也學進去。這種圖在畫風地圖上和原圖幾乎同一點，分群找不到，只有這項檢查會列出。用 AI 放大過的圖通常不會被列出。檢查時會先把圖縮到訓練尺寸（約 1024×1024）再看，縮小後仍清晰的圖（例如大畫布上柔和的筆觸）不會被列出。
- 壓縮很重的 JPEG（品質低於 70）：品質 60 以下的 JPEG 會讓畫風判斷明顯失準，能找到原圖就換成原圖。
- 長寬比極端的圖。
- 截斷的檔案。
- 動圖。
- 只靠 EXIF 標記轉正的圖（多半是手機拍的照片）：看圖軟體和本工具會照標記轉正，但 kohya sd-scripts 讀的是存檔時的方向，會把它橫著或倒著訓練。用本工具匯出（`--export` 或網頁的「匯出」）時會自動把它轉正後存出，原檔不動；直接拿原資料夾訓練的話，要先用看圖軟體轉正後另存。ai-toolkit 和 OneTrainer 會自己轉正，不受影響。
- 缺標註或標註是空的。全部都沒有標註也能訓畫風 LoRA：kohya 會改用資料夾名稱裡的觸發詞（見步驟 3）。要標註的話，先用 WD14 tagger 之類的工具產生；style-atlas 不會產生標註。
- 另外會列出**出現在一半以上標註的標籤**和比例（例如 `1girl 95%、white shirt 87%`）。幾乎每張訓練圖都有的內容（同一個角色、同一套衣服）會和畫風一起被學進去；如果它不是畫風本身，補一些不含它的圖。
- 同一個標籤在資料集裡有兩種寫法（有的 `long_hair`、有的 `long hair`）：文字編碼器會當成兩個不同的詞，標籤的意思就被拆開了。列出的是用了少數寫法的標註，改成和其他標註一致；或在匯出時加 `--fix-tag-spelling`（網頁：「統一標籤寫法」），匯出的複本會統一成多數標註的寫法，原始標註不動。
- 標註裡有 `watermark`、`signature`、`artist name`、`web address` 這類標籤的圖：圖上有浮水印或簽名，LoRA 會一起學進去。可以裁掉、排除，或把那個標籤留在標註裡（讓模型把它歸給那個標籤，而不是畫風）。
- 混在彩色圖裡的黑白圖（例如草稿、漫畫頁）。整個資料夾大多是黑白時不會列出，因為那是畫師本身的風格。
- 其中標註沒有 `monochrome` 或 `greyscale` 的黑白圖：LoRA 會把「黑白」當成觸發詞畫風的一部分。補上標籤或排除。Danbooru 上約 15% 的黑白圖也漏了這兩個標籤，所以從 Danbooru 抓來的標註也要看。
- 標註寫 `greyscale`、圖卻明顯有顏色（例如裱框照片、局部上色、帶色調的草稿）：改成 `monochrome` 加上顏色標籤，或拿掉 `greyscale`。只有 `monochrome` 的單色圖不會列出，那本來就對。

## 2. 看一遍，再決定怎麼分

先看「檢查」分頁最上面的**畫風一致性**（`cluster` 指令也會印出來）。注意：分出好幾群不代表混了不同畫師，單一畫師的 20 張圖約三分之二也會分成 2 群以上（子畫風、時期）；要判斷有沒有混到別的畫師，看的是一致性：比 90% 的單一畫師還分散時，資料夾可能混了不同畫風或時期，值得分群看看、必要時分開訓練。兩位畫師混在一起時大約一半抓得到，三位約 85%，五位都抓得到（另外約 11% 的單一畫師會被誤判）；同一個模型、同樣角色的 AI 算圖則會顯得很一致，不適用。

```bat
style-atlas serve "D:\lora\artistX" --time name
```

在網頁介面裡依序看這幾頁：

- **重複**：同一張圖、裁切、表情差分、同場景連續畫面。重複圖會讓模型過度學那一張。
- **檢查**：上方的「開始檢查」會列出步驟 1 的問題圖（和 `audit` 相同），下方是草稿、漫畫頁、截圖這類通常不合群的圖。不要的按 X 排除。
  - 混進了別的畫師的圖（例如抓 tag 時抓到的）：它們彼此很像，不一定會出現在不合群清單裡。先把看到的兩三張按 X 排除，再按排除清單上方的「找更多像這些的」，其餘的通常都會排在最前面，逐一點選後按 X。
- **畫風群**：每群旁邊的時間分佈，可以看出哪一群是早期、哪一群是近期；有標註時還會列出這群特別常見的標籤。
  - 預設的門檻是「自動」，會依圖片決定。想按時期拆，把左下的分群選單切到「時期（單一畫師）」，在旁邊填要分幾段（預設 3），再按「重新分群」。幾乎每張圖都會分進其中一段，連草稿這類不合群的圖也會，所以先在「檢查」分頁把不要的按 X 排除。圖少於約 100 張時，分段界線不太穩定。
  - 分錯的圖可以手動移到別群、合併兩群，或把一群拆成兩群。改錯了按「復原」或 Ctrl+Z。
  - 要處理很多張時，按住 Shift 點圖或在地圖上拖框選取，再一次排除或移到別群。
  - 打開一群按「找更多像這群的」，可以把被分到別群或沒分到的同類圖找回來。
  - 幫每群取名（例如「早期」「線稿期」），匯出的資料夾和觸發詞就會用這個名字。
- **擴充資料集**（選用）：手上只有十幾張某種畫風的圖時，可以用 `style-atlas search 範例資料夾 --combine --in 大圖庫 --top 100 --copy-to 輸出資料夾` 從大圖庫裡找出更多同風格的圖。
- **口味**（選用）：在評分模式下一直按 L／D，評約 10 張就能得到粗略的偏好排序。

網頁開著時，這個 console 視窗會一直被占用。看完後按 Ctrl+C 停掉，或另開一個 `StyleAtlas-console.bat` 視窗做步驟 3。

## 3. 匯出成 kohya 資料夾

```bat
style-atlas cluster "D:\lora\artistX" --layout kohya --name artistX --dedupe --drop-outliers 5 --export copy
```

- **在網頁上做過移動、合併、拆群或取名時，請改用網頁的「匯出資料夾」**（選 kohya、填「LoRA 名稱（資料夾名）」，必要時勾「標註加觸發詞」）：只有它會用到這些手動修正。上面的 `cluster` 指令會重新分群，只沿用你按 X 排除的圖（放進 `_excluded\`）。
- 每群會匯出成 `<repeats>_artistX_styleNN\` 資料夾（取過名的群用名字），標註檔一起複製。
- 檔名帶有時間（Pixiv、Danbooru 作品編號、推文編號，或 `2023-05-12` 這種日期）時，用 `--granularity timeline --time name`：依時間順序，在畫風變化最大的地方切成 3 個連續的時期（`--k` 改段數；切點放在變化最大處，所以各時期的張數不會平均，例如 9、7、44 張），再用兩個檢定告訴你是哪一種情況：
  - **沒找到和時間的關係**：這些時期可能只是任意切點，合在一起訓練比較穩妥。作品少時只看得出大的變化，所以這不代表畫風完全沒變。
  - **只有漸變**：畫風隨時間改變，但沒找到明確的轉折點，切點可能只是把連續的變化切開。通常合在一起訓練即可；想要某個時期的畫風，就只留那一段。作品不到約 100 張時，幅度不大的單一轉折也可能落在這裡。
  - **有轉折**：變化比隨時間平滑變化的曲線更突然，分開訓練有道理。
  - 去掉近重複後作品太少（3 段時少於 30 張）時不做檢定，請直接看圖。

  實測 14 位 Danbooru 畫師：1 位有轉折、5 位只有漸變、6 位沒找到和時間的關係、2 位太少；有 6 位的 p 值在邊緣，會註明往哪一邊偏，例如「有一點和時間有關的跡象，但不夠確定」（docs/BENCHMARKS.md）。連續發表的相似作品（一個系列）只算一次。大多數畫師是漸變，所以通常一個 LoRA 就夠。段數換很多種試，總有一種會碰巧顯示「有轉折」，請以一開始選的段數為準。

  決定訓一個 LoRA 時，把 `--granularity timeline` 換成 `--k 1` 再匯出一次，全部作品會放進同一個資料夾（指令結束時也會提醒）。預設的自動分群常把一位畫師分成好幾群（大多只是同一畫風裡的細部差異），想要一個資料夾時一樣加 `--k 1`。
- 指令最後會印一行張數明細（例如「共 60 張：44 張在 1 個畫風資料夾；另外放：_duplicates 11, _outliers 5」），說明每張圖去了哪裡。repeats（資料夾名稱前面的數字）是自動算的：讓每個資料夾每個 epoch 約 100 張，張數少的資料夾重複較多次；要自己指定就加 `--repeats N`。
- 沒有時間資訊、或想純粹依畫風拆時，用 `--granularity period --time name`（`report` 加 `--time name` 也會在每群標出時間位置，方便存檔或傳給別人）。指令會在每群後面印出它在作品時間軸上的位置，例如 `when 9% [3%-28%]` 表示這群的中位數落在最早的 9%（中間一半落在 3%～28%），一看就知道哪群是早期、哪群是近期。
- repeats 會自動調成「張數 × repeats ≈ 100」，也可以用 `--repeats N` 指定。例如某群 20 張 → repeats 5，每個 epoch 這群看 100 次；batch size 1 時就是 100 步，訓 10 個 epoch 是 1,000 步。張數少的群 repeats 高，各群份量就接近。匯出完網頁和 `cluster` 指令都會直接告訴你每個 epoch 約幾步。
- 某群太多張（例如 300 張）時，加 `--max-per-group 40`（網頁：「每群最多幾張」）只保留 40 張能涵蓋整群變化的圖，其餘放到 `_trimmed\`。
- 匯出資料夾裡會一起寫一份 `dataset_config.toml`（kohya sd-scripts 用 `--dataset_config` 指定），列出每群的資料夾路徑與 repeats；有勾觸發詞時會設 `keep_tokens = 1`，讓觸發詞在打亂標籤時固定在最前面。解析度與 batch size 請依模型自行調整（SDXL／Illustrious／Anima 用 1024）。
- 用其他訓練器時：同一個資料夾還有 `diffusion_pipe_dataset.toml`（diffusion-pipe：在訓練設定的 `dataset` 填這個檔；在 WSL 裡要把 `D:\` 改成 `/mnt/d/`）和 `onetrainer_concepts.json`（OneTrainer：複製到 OneTrainer 的 `training_concepts\` 資料夾，再到 concepts 分頁的下拉選單選它），以及 `ai_toolkit_datasets.yaml`（ai-toolkit：把裡面的項目貼到訓練設定的 `datasets:` 底下）。四份的資料夾與 repeats 都一樣。
- 標註裡有描述畫風本身的標籤（例如 `sketch`、`monochrome`）時，加 `--strip-tags "sketch, monochrome"`（網頁：「要移除的標籤」）把它們從匯出的標註拿掉，讓觸發詞去學這個畫風。原本的標註不會被改。
- 被排除的圖放在 `_duplicates\`、`_outliers\`、`_unassigned\`、`_excluded\` 這幾個資料夾。它們沒有數字前綴，所以 kohya 不會拿來訓練。
- 每次匯出都會在輸出資料夾寫一份 `clusters.csv`：每張圖一列，`folder` 欄寫它去了哪個資料夾。去了 `_duplicates`、`_outliers`、`_excluded`、`_trimmed`、`_unassigned` 的，資料夾名稱就是原因，可以用試算表核對。
- 之後**又加了新圖**：照樣用 `StyleAtlas.bat` 打開同一個資料夾。之前的取名、移動、合併和排除都會保留，新圖先放在「未歸類」。點開「未歸類」按「各自放進最像的畫風」，夠像的會自動放進最像的群（和 `sort` 同一套規則，可以復原）；剩下的手動移，或按「重新分群」。
- 新圖放在**另一個資料夾**、想直接分進已匯出的資料夾：`style-atlas sort "D:\new" --into "D:\lora\artistX_style_atlas\folders" --by-folder --export copy`。每張會放進最像的那群（例如 `10_artistX_style01\`），不夠像的放 `_unsure\`，和資料集重複的放 `_already_in_dataset\`，再把它們搬進對應資料夾即可。資料集是用 `--trigger-captions` 匯出的話，`sort` 也加 `--trigger-captions`，放進去的新圖標註開頭會加上同一個觸發詞。實測同畫師的新作品約 69% 會被判符合（其中 99% 放對群），其他畫師約 9%；每群只有 10 張左右時，其他畫師會到 14%，記得看一下各群新放進的圖。資料夾是 kohya 格式（例如 `10_artistX_style01`）時，`sort` 會順便告訴你補圖後要改成幾 repeats（例如改名成 `7_artistX_style01`），讓每群每個 epoch 的份量維持在約 100；訓練設定檔（`dataset_config.toml` 等）裡的 repeats 也要跟著改。
- 想**一群訓一個 LoRA**（例如早期、近期畫風分開）：把那一群的資料夾單獨當 train_data_dir。
- 想**同一個 LoRA 裡分成幾個概念**：保留全部資料夾，並讓每群有自己的觸發詞。注意兩點：
  - kohya 只有在**沒有標註檔**時，才會拿資料夾名（`artistX_styleNN`）當標註。
  - 有標註檔時，要把觸發詞寫進每個標註的開頭（可搭配 `keep_tokens`）。加 `--trigger-captions` 會自動幫你做：
    - 匯出的每個標註開頭會加上 `artistX_styleNN, `；
    - 沒標註的圖會新建一個只含觸發詞的標註；
    - 原始標註不會被改；標註原本就有的標籤（例如你自己的 `artistx`）會保留在後面，但只有第一個觸發詞會被 `keep_tokens = 1` 固定；
    - 匯出後會列出寫進去的觸發詞。群名是中文時觸發詞也會是中文，SD 1.5、SDXL 的文字編碼器對中文支援差，會提醒你群名改用英文。

## 4. 訓練完之後

- 想要一頁可以保存或傳給別人的檢查結果：`style-atlas report "D:\lora\artistX" --renders "D:\lora\test_renders"`。報告會多一段「LoRA 算圖檢查」：畫風距離和判定、有幾張落在訓練集某一群的範圍內、外觀差在哪裡（例如「偏冷、線條多」）、可能背下的訓練圖（算圖和訓練圖並排），以及最不像訓練集的算圖。算圖最好 8 張以上，才會判斷整批。
- 用 LoRA 算一批圖（10 張以上，主題盡量多樣），整批拖進網頁介面。畫面會告訴你這批圖有幾張「和這個資料夾裡某一群的畫風夠接近」：實測同一畫師沒用到的作品約 61% 會落在範圍內，其他畫師約 1%，所以看整批的比例，不要看單張。
- 同一個畫面會另外列出「和資料夾裡的某張幾乎一樣」的圖（同一張圖、裁切或調色等級的相似）。LoRA 算的圖出現在這裡，代表它可能背下了那張訓練圖（過擬合），可以降低 repeats 或 epoch，或檢查那張圖是不是重複太多次。
- 想要一個數字：`style-atlas compare "D:\lora\artistX" "D:\lora\test_renders"` 會給畫風距離和 z 值（差距是同一畫風內部雜訊的幾倍），以及外觀差在哪裡（例如「偏冷、線條多」），並逐一列出和某張訓練圖幾乎一樣的算圖（`--json` 輸出全部數字）。

## 5. 一般實務建議（非本工具的測量結果）

- **張數**：畫風 LoRA 的常見建議是 15–30 張就夠，超過約 50 張效果遞減，8–15 張可以先試。畫風要一致，主題（角色、場景、構圖）反而要多樣。
  - 來源：https://help.scenario.com/en/articles/training-a-style-lora 、https://apatero.com/blog/ultimate-guide-lora-training-2025
- **標註寫內容，不寫畫風**：標註描述畫了什麼，畫風交給 LoRA 去學。2026 年有一篇研究特地把標註改寫成只描述客觀內容，因為描述畫風的字眼會混進標註裡，模型就不會把畫風學給觸發詞。
  - 來源：https://arxiv.org/pdf/2603.16649
  - Illustrious 一類模型可以用 Danbooru 式 tag：https://offlinecreator.com/guide/illustrious-lora-training-guide
  - 本工具不產生也不改寫標註內容（`--strip-tags`、`--trigger-captions` 只動匯出的副本），標註請依你的模型慣例準備（Danbooru 標籤或自然語言句子）。
- **kohya 的 repeats 與標註選項**：資料夾前綴 `N_name`（或 TOML 的 `num_repeats`）決定 repeats；`shuffle_caption` 與 `keep_tokens` 是常用的標註選項。
  - 來源：https://www.mintlify.com/kohya-ss/sd-scripts/quickstart
- **其他過濾工具**：deepghs 的 imgutils／waifuc 能濾掉單色圖、漫畫頁、多角色圖，也能用 CCIP 認角色，可以和本工具搭配使用。
  - 來源：https://github.com/deepghs

## 6. 要知道的限制

- 2～5 位畫師混在一起時，分群和畫師的吻合度約 ARI 0.5（ARI 0～1，1 表示完全吻合）；畫師越多越低（50 位時約 0.38）。同一畫師拆時期時，「時期」（分 3 段）和發表時間的吻合度明顯比預設的自動門檻好，但整體仍偏弱（13 位測試畫師的平均吻合度 AMI 約 0.12，0 是亂分、1 是完全對上）；作品少時分段結果不太穩定。所以分群是**初步整理**，請在地圖上確認。
- 同一個角色出現在很多畫風時，畫風向量會被角色外觀拉走。遇到這種收藏可以加 `--ignore-characters`（或在網頁「進階…」勾選「忽略角色軸」）；但不要用在混了不同畫師的資料夾。
- 近重複門檻刻意設得保守（0.95）。在 0.92～0.95 之間，常常是同角色換了姿勢的不同圖，對訓練來說那是有效的圖。

詳細數字見 [BENCHMARKS.md](BENCHMARKS.md)。

## 7. 指令輸出的語言

中文 Windows 上，`cluster`、`sort` 等指令的主要訊息（分群結果、一致性、匯出、補新圖的摘要、計算進度）會自動用中文；想看英文就先執行 `set STYLE_ATLAS_LANG=en`（反過來 `zh` 強制中文）。`audit` 的項目名稱會在後面附上中文（例如 `no_caption（沒有標註檔）`）；其他指令的訊息、選項錯誤和 `--help` 說明也都有中文。下表是英文訊息（非中文系統，或設了 `STYLE_ATLAS_LANG=en`）的意思；中文系統上，大多數本來就會直接顯示中文：

| 輸出 | 意思 |
|---|---|
| `5 styles, 2 unassigned (agglomerative, cut 0.47 (auto))` | 分成 5 群，2 張沒有分進任何群；切分距離 0.47 是自動選的 |
| `style consistency: spread 0.74, more spread than 64% of single artists` | 畫風一致性：比 64% 的單一畫師分散（越高越可能混了不同畫風） |
| `(few images)` | 這群張數少，訓練時可能不夠 |
| `[brighter, less colourful, more line work]` | 這群和整個資料夾比：偏亮、色彩淡、線條多 |
| `when 9% [3%-28%]` | 這群在作品時間軸上的位置：中位數在最早的 9%（加 `--time name` 才有） |
| `one epoch = 400 steps at batch size 1` | batch size 1 時，每個 epoch 約 400 步 |
| `note: style 03 kept too few images ...` | 第 3 群的圖都被當成重複或離群而拿掉，所以沒有資料夾（編號跳過） |
| `N near-duplicates set aside before grouping` | 有 N 張近重複圖先放到一邊，不參與分群 |
| `_unsure`、`_already_in_dataset`（`sort`） | 不夠像任何一群；和資料集裡的某張幾乎一樣 |
| `X% fit their group: mostly the dataset's styles` | 新圖有 X% 符合某一群：大多是資料集的畫風 |
| `smaller_than_min_side`、`no_caption`、`soft_or_enlarged`（`audit`） | 短邊太小、沒有標註檔、像是放大過的圖 |
| `low_jpeg_quality`、`watermark_or_signature` | JPEG 壓縮太重、標註裡提到浮水印或簽名 |
| `buckets (kohya, 1024)` | 圖片會分進哪些 kohya 長寬比 bucket，各幾張 |
| `ranked by style match in the search space ...`（`search`） | 名次依畫風相似度排序；旁邊的數字是一般的相似度，所以不一定照大小排 |
