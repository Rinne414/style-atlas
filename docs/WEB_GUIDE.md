# 网页界面图解：探索画风，以及训练 LoRA 前的三个步骤

双击桌面上的 **Style Atlas**，按“打开图片文件夹…”或把文件夹拖进窗口，就会打开下面这个画面（用浏览器的话，照旧把文件夹拖到 `scripts\StyleAtlas.bat` 上）。看画风和整理 LoRA 用的是同一个画面：

- **找图 · 看画风**：地图、右侧的“画风组”“画师”“偏好”标签页。
- **训练 LoRA**：右侧的“LoRA 数据集”标签页有“① 检查数据 → ② 整理画风组 → ③ 导出”、检查和重复的图，按顺序点即可。

操作：左键拖动移动地图、右键拖动转动、滚轮朝鼠标指的地方缩放；双击图片看大图（← → 换下一张、Esc 关），双击空白处放大那里。字太小或太大时，在“查看”菜单调“界面大小”，或按 Ctrl + / Ctrl −。

截屏里的图片是 `style-atlas demo` 生成的抽象图，不是任何人的作品；想先试玩也可以用它。

## 找图 · 看画风

1. **看地图**：每张缩略图是一张图，外框颜色是自动分出的画风组。上方可以切换两种版面：“分组排列”把每组排成一块、上面写组名，图一张挨一张不会互相盖住（块和块的位置不代表相似度）；“真实分布”里靠得越近画风越像（压成 3D，只是大概）。想知道哪两组最像，看组卡片上的“最接近”。
   - 滚轮往鼠标指的地方放大，左键拖动移动（“真实分布”里右键拖动旋转）。拉近时图会自动换成清楚的文件，放得够大时直接用原图。
   - 鼠标停在图上，画面另一侧会出现大张预览，停一下就换成原图。按空格键（或双击图）开看图器：滚轮放大看笔触、拖动移动、点一下在整张和原尺寸之间切换，← → 看上一张/下一张（到组尾会接着下一组）。
   - **一张一张看，不跳过**：在地图上按 → ← 依次看下一张/上一张（按右边画风组的顺序，组里由上到下、由左到右），↑ ↓ 换上一行/下一行。目前这张在地图上会框起来，另一侧显示大图和“画风 3 · 12 / 241（全部 1,000 / 2,206）”；Enter 开大图，Esc 结束。有筛选或搜索结果时只看亮起来的图。下次打开同一个文件夹，会从上次看到的地方继续。
   - “回到全图”只有在拉近、移动、点开某组或筛选之后才能按；已经是整张地图时是灰的。
   - “查看”菜单的“图墙格子”可以选“正方形”（排得整齐）或“按图片比例”（竖图排得更紧密、横图按实际宽度）。
2. **看每一组是什么**：右侧“画风组”标签页的每张卡片有一句外观描述（例如“偏冷、线条多”）；文件夹底下按画师分子文件夹时，会写出这组主要“来自”哪位画师。点卡片会飞过去看那组。卡片写“其中 N 张互为近重复”时，到“重复”标签页看是哪些（同一张图的不同版本）。
3. **哪些画师画风相近**：文件夹底下按画师分子文件夹（3 个以上）时，下方会有“画师地图”：每位画师一个点，放在他的平均画风上，画风相近的画师分成几个家族，在新标签页打开，也保存为 `artist_map.html`（可以传给朋友）。
4. **比较两组**：点开一组，用“和…比较”选另一组，最上面是两组的距离放在“两位不同画师”里的位置（例如“比一半的‘两位不同画师’还远”；工具分出来的组是刻意切开的，距离会偏大），每一排先列最能代表差异的图。
5. **找相近的图**：点任一张图，按详情最上面的“找画风相近的图”；或按左下“以图搜索…”、把图拖进画面。结果标“很像”（0.85 以上，9 成是同一位画师）或“像”（同一位画师两张作品的中位数以上），可以按“把这 N 张复制到文件夹”一次收集起来。一组的大查看里也有“把这 N 张复制到文件夹”。
6. **找画风相近的画师**：文件夹底下按画师分子文件夹时，右侧有“画师”标签页：找到一位画师，就列出平均画风最接近的 8 位；“在地图上看”标出他的图，“和…比较”直接用画师名字比较两位。
7. **换个角度看**：“查看”菜单选“指标轴版面”，X/Y/Z 各选一种测量（亮度、鲜艳度、线条量、冷暖…），看整个文件夹怎么分布。
8. **量化自己的偏好**：右侧“偏好”标签页按“评下一张最有用的图”，看到喜欢的按 L、不喜欢的按 D（状态栏会显示目前各评了几张）。两种各满 5 张后，模型会用画风向量学你的偏好：列出还没评过的图里你最可能喜欢和最不可能喜欢的，版面的指标轴也多一个“偏好分数”。AUC 是用你评过的图交叉验证的，评得少、或喜欢和不喜欢差很多时会偏高；评过的画风够多时，下面还有一个“整组相似画风留出来验证”的 AUC，比较接近遇到没评过的画师时的表现（实际通常再低一点）。它分得出喜欢和不喜欢，分不出好和更好。
9. **记下发现**：点一张图，在详情的“给这张图加备注”打一句话按 Enter，地图上就会显示。
10. **分享**：“保存为分享用地图”保存为一个 HTML 文件，传给朋友直接打开（备注和组名都在里面）。保存前可以选图要多清楚：只有缩略图（文件最小，但拉近和大图会糊）、清楚（320 px）、最清楚（512 px），每一种都会先显示大约多少 MB；选清楚的话，对方鼠标预览、拉近和看大图都看得清楚；也可以在“查看”菜单按“保存为图片”（或键盘 P），或“录一圈”录成视频。

## ① 检查数据

![检查标签页：按“开始检查”，最上面是画风一致性，下面列出问题图；“选中这些”一次选起来，再用上方的“排除这 N 张”](images/guide_1_check.jpg)

1. 打开右侧的“LoRA 数据集”标签页，点“① 检查数据”，再按“开始检查”。最上面一行是**画风一致性**：和 114 位画师比，这个文件夹的画风有多分散。显示“可能混了不同画风或时期”时，到“② 整理画风组”看看要不要分开（约 1 成的单一画师也会落在这里；两位画师混在一起约一半抓得到）。接着会列出：
   - 太小的图（短边可以选 512/768/1024 px）；
   - 小图放大或很模糊的图、压缩很重的 JPEG（LoRA 会学到模糊和压缩痕迹）；
   - 混在彩色图里的黑白图（例如草稿、漫画页），以及其中标注没有 `monochrome`/`greyscale` 的；
   - 标注写 `greyscale`、图却明显有颜色的；
   - 长宽比极端的图、没有标注或标注是空的、动图、文件不完整或打不开；
   - 只靠 EXIF 标记转正的照片（kohya 会把它横着训练）；
   - 标注提到水印、签名或网址的图；
   - 同一个标签有的写 `long_hair`、有的写 `long hair` 时，用了少数写法的标注。
2. 每一类都有“选中这些”。按下去，地图上那些图会亮起来，上方出现一条“已选 N 张”：
   - “排除这 N 张”：导出时放到 `_excluded\`，不会拿去训练；
   - “恢复这 N 张”：取消排除；
   - “移到其他组…”：一次移到某一组。
3. 下面的“最不合群的图”是和整组最不像的图，也可以逐张点击后按键盘 X 排除。
4. 混进了别的画师的图时：先排除看到的两三张，再到同一页的排除清单按“找更多像这些的”，其余的通常都会排在最前面。

也可以自己选：按住 Shift 点图，或按住 Shift 在地图上拖一个框。Esc 清除选中。选了 2 张以上时，上方的“和…比较”可以拿这些图和任一组比画风（例如检查一批疑似别人画的图，是不是真的和这组不同）。想比两批自己选的图（例如早期几张和近期几张）：先选第一批按“记住这批为 A”，再选第二批按“和 A 比较”。

## ② 整理画风组

![一组的大查看：最典型的图在前、不太像这组的另列一排、最像的组并排比较](images/guide_2_groups.jpg)

1. 点“② 整理画风组”，右侧每一张卡片是一组：
   - 一句外观描述，例如“偏冷、线条多”；
   - 文件夹底下有子文件夹（例如每位画师一个）时，“来自：”会列出这组的图主要来自哪几个子文件夹，一眼看出哪一组是哪位画师；
   - “最接近”的 3 组，点一下就跳过去，方便决定要不要合并。
2. 点一张卡片，地图的位置会换成**这一组的大查看**（←、→ 换上一组/下一组，Esc 或“回到地图”回去，地图上这组会亮起来）：
   - 全部的图，**最典型的排在前面**（最靠近这组的平均画风）；右上角可以调缩略图大小；
   - “**不太像这组的 N 张**”：离这组中心比组里其他图都远得多的图（超过上四分位数再加 1.5 倍四分位距），常是另一种画风、草稿或不同媒材。Shift+点击标记后，用出现的工具栏移到别组或排除；
   - 最下面是**最像的 3 组并排**，每组 8 张最典型的图，看起来是同一种画风就按“把这组并进 …”（再按一次才会合并）；
   - 合并、移动、改名之后页面会刷新，大查看会自动打开在刚才那组（或合并后的那组）。
3. 大查看上方的按钮可以：
   - 取名（之后的文件夹名称和触发词都会用这个名字）；
   - “把这组合并到…”（选好目标后，再按出现的“把 A 合并到 B”才会合并；合错了按“撤销”或 Ctrl+Z）、“拆成两组”“找更多像这组的”；
   - “和…比较”：列出两组的画风距离、它在“两位不同画师”里的位置（两边各 5 张以上时；少于 5 张时用 z 值），以及外观差在哪里。
4. 分得不好时，用左下的分组菜单：
   - 同一位画师的文件夹：选“中”，或选“时期（单一画师）”再填段数；
   - 文件名带有时间（Pixiv、Danbooru 作品编号、推文编号、日期）时，菜单会多一个“按时间分时期”（文件名的编号来自不同来源时，例如推文编号和 Pixiv 编号混在一起，排不出先后，就不会出现）（`StyleAtlas.bat` 打开时就会读文件名里的时间；自己打命令时加 `--time name`）：按时间顺序在画风变化最大的地方切成连续的时期，重新分组后下方会说明是哪一种情况：没找到和时间的关系、只有渐变（通常合在一起训练即可），或有转折（分开训练有道理）；作品太少时不做判断，结论在边缘时会注明。连续发表的相似作品（一个系列）只算一次。作品只有几十张时，结论请当成提示，以地图上看到的为准。大文件夹约需几秒。决定训练一个 LoRA 时，菜单选“全部一组（训练一个 LoRA）”再按重新分组，全部作品就会放进同一个文件夹；
   - 很多位画师混在一起的图库（20 位以上）：选“按画师（20 位以上的图库）”，分出的组会比较贴近画师；
   - 改完按“重新分组”。任何修改都可以按“撤销”或 Ctrl+Z 回去。
5. 同样的角色出现在很多画风时，打开“高级…”勾选“忽略角色轴”。

## ③ 导出

![导出对话框：左边勾要导出的组，右边选每组各一个 LoRA 或合成一个、名称、存放位置和格式，下面实时显示会写出什么](images/guide_3_export.jpg)

点“③ 导出”（或左下的“导出训练数据集…”、一组大查看里的“导出这组…”）会打开导出对话框。原本的图和标注都不会被移动或修改。

- **左边勾要导出的组**：每组有几张代表图、组名、几张进训练、会放到哪个文件夹。没勾的组完全不会被复制。一开始会勾 3 张以上的组；从“导出这组…”打开时只勾那一组。
- **每组各一个 LoRA**（默认）：每个勾选的组各自一个文件夹 `<名称>_<组名>`，各有自己的触发词和训练配置文件。**合成一个 LoRA**：一个文件夹，每组是里面的子文件夹、各有触发词，一个 LoRA 学全部（同一位画师分时期时常用）。
- **触发词**：每个勾选的组旁边有一格，默认显示自动生成的名字（名称加组名），可以直接改成你要的（例如 `artistx_early`）；它同时是那组的文件夹名称。两组改成一样时会提醒你。“触发词写进每个标注的开头”默认打勾，训练时才用得到触发词。
- **存到**：默认放在文件夹旁边的 `<文件夹名称>_style_atlas\`；程序窗口里按“选择…”可以选别的地方（不能选这个文件夹里面，不然训练程序会连副本一起读）。同名文件夹已经有东西时会自动加上 `_2`。
- 右下会实时显示会写出几个数据集、各几张；按“导出 N 张”开始，完成后按“打开文件夹”。

| 选项 | 用途 |
|---|---|
| 文件夹格式：普通文件夹 / kohya | kohya 会做成 `10_名称_style01` 这种文件夹，并附 kohya（`dataset_config.toml`）、diffusion-pipe、OneTrainer、ai-toolkit 的配置文件 |
| 名称 | 文件夹和触发词的开头（空白时用文件夹名称） |
| 每组最多几张 | 某组太多时只留这么多张，会挑能涵盖整组变化的；其余放到 `_trimmed\` |
| 要移除的标签 | 例如 `sketch, monochrome`，导出的标注里会拿掉这些标签 |
| 统一标签写法 | 文件夹里有两种写法的标签（`long_hair`/`long hair`）时，导出的标注统一成多数标注的写法；原始标注不动 |
| 标注加触发词 | 每个标注最前面加上该组的触发词：`名称_组名`（例如 `artistx_style01`；组有取名时用组名），配置文件用 keep_tokens = 1 把它固定在第一个；标注原有的标签都保留。触发词是中文时会提醒：SD 1.5、SDXL 的文字编码器对中文支持差，组名建议用英文 |

之后又加了新图时，用同一个文件夹重新打开即可：取名、移动、合并和排除都会保留，新图先放在“未归类”：点开它，按“各自放进最像的画风”，够像的图会放进最像的组（要和那组七成的图一样接近组中心），其余留着让你手动处理；这一步可以撤销。

勾选的组里被排除、重复或超过上限的图，会放到同一个数据集里 `_` 开头的文件夹（`_excluded`、`_duplicates`、`_trimmed`），方便检查，不会拿去训练。kohya 格式会同时附上 kohya、diffusion-pipe、OneTrainer、ai-toolkit 的配置文件（用法见 [LORA_GUIDE.md](LORA_GUIDE.md) 步骤 3）。

导出完成的消息会说明：

- 复制了几张、其中几张用来训练（其余在“未归类”和 `_` 开头的文件夹，例如 `_duplicates`、`_excluded`）；
- 哪几组在去掉重复和排除的图之后不足 3 张，被放进未归类；
- kohya 格式时，每个 epoch 约几步；repeats 会自动调整，让每组每个 epoch 约 100 张（张数 × repeats）；
- 有几张训练图短边小于 512 px（用 1024 训练时会被放大而模糊）；
- 只靠 EXIF 标记转正的照片，导出时已经转正后存出（原文件不动）；
- 写进标注的触发词。

导出对话框的选择（勾的组、触发词、格式、名称、存放位置）会记住，下次打开同一个文件夹还在；重新分组、合并或拆组之后，勾选和触发词会重新开始（组的编号已经代表不同的组）。

## 其他好用的功能

![指标轴版面：X 冷暖、Y 线条量、Z 鲜艳度](images/guide_4_measures.jpg)

- **以图找图**：把一张或几张图拖进画面。每张结果左下角是画风相似度（cos）。参考值是在 306 位 Danbooru 画师上量的：同一位画师的两张作品中位数 0.59，不同画师 0.43；0.85 以上会标色，这样的配对有 9 成是同一位画师。在几千张的图库里，0.75 左右的结果常常是别的画师，不代表同一人。只拖一张图时，可以勾“只看很像的”只留 0.85 以上的结果（复制到文件夹时也只复制这些）。拖多张图时，分数是和这几张的共同画风比，会比单张比对高。结果下方的“把这些复制到文件夹”会连同标注复制到文件夹旁边新的 `search_matches` 文件夹（扩充训练集时好用）；几乎相同的图会自动收起。拖多张时，还会告诉你这批图有几张“落在这个文件夹某一组的范围内”，可以用来检查 LoRA 算出来的图像不像训练集。拖进来的图如果和文件夹里的某张几乎一样（同一张图、裁切或调色），会另外列出来：LoRA 生成的图出现在这里，代表它可能背下了训练图。打开的文件夹底下有子文件夹（例如每位画师一个）时，还会列出“最像的子文件夹”和分数（和文件夹平均画风的相似度；0 或负数表示不比一般的文件夹像），点一下只显示那个文件夹的图。
- **指标轴**：“查看”菜单选“指标轴版面”，X/Y/Z 可以各选一种测量，例如冷暖、线条量、鲜艳度、偏好分数、原创度。
- **原创度**：在“高级…”填一个已知画风的文件夹（画师作品、配方），按“加载参考”，指标轴就会多出“离参考集距离”。
- **#标签筛选**：上方的筛选框打 `#monochrome`，只亮出标注里有这个标签的图。这时候以图搜索，就只会在这些图里找（例如 `#solo` 只找单人图）。
- **录一圈**：把 3D 地图转一圈录成 8 秒的视频，可以直接分享。
- **保存为图片**：“查看”菜单的“保存为图片”（或键盘 P），把目前的 3D 画面保存为 PNG；分享用的地图文件里也有这个按钮。
- **保存为分享用地图**：保存为单个 HTML 文件，传给朋友就能打开。
- **保存为画风报告**（在“高级…”里）：把这个文件夹的画风整理成一页：画风一致性、外观和 278 位画师比的位置（例如“比 89% 的画师更亮”）、各组的代表图，用的是你取好的组名；排除（X）的图不算在内。（报告的外观比较用的是 278 位画师的作品；画风一致性的参考是另一组 114 位画师，两个数字不一样是正常的。）
- **看一张图的详情**：点地图上的图，右侧“详情”会显示大图、所属的组、离群度和标注文件里的标签，还有喜欢/不喜欢、排除、移到其他组等按钮。
- **在地图上加备注**：在详情的“给这张图加备注”打一句话（例如“金发贵族系列”），按 Enter，地图上那张图旁边就会显示这句话；保存为分享用地图时也会一起带着，方便把探索到的东西指给朋友看。清空后按 Enter 即删除。备注存在文件夹旁边的 `notes.json`。
- 按 `?` 看地图的说明（点代表什么、距离和颜色的意思）和所有快捷键；鼠标停在按钮上会有说明。拖动地图后会停止自动旋转。
